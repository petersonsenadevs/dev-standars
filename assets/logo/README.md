# Logos de Senzu

Copia de los logos oficiales. El original y todas las versiones están en el repo de la web
(`senzu/design-system/senzu/logos/final/`): si cambian allí, se copian aquí; **no se editan estos SVG**
(la palabra está convertida en trazos).

| Archivo | Uso |
|---|---|
| `senzu-horizontal-color-claro.svg` | Cabecera del README en tema claro (semilla verde, palabra oscura) |
| `senzu-horizontal-color-oscuro.svg` | Cabecera del README en tema oscuro (semilla verde, palabra blanca) |
| `senzu-symbol.svg` | Solo la semilla, en verde bosque |
| `senzu-symbol-512.png` | Avatar e icono |

Reglas:
- `color-oscuro` (palabra blanca) SOLO sobre fondo oscuro; en fondo claro, `color-claro`.
- Tamaño mínimo del horizontal: 20 px de alto; por debajo, solo el símbolo.
- Zona libre alrededor: la altura de las minúsculas de «senzu».
- No rotar, no recolorear, no añadir sombras ni contornos, no reescribir la palabra con una fuente.
- Colores: verde bosque `#1F6B4F` · verde brote `#3DDC84` · tinta `#0E1110` · blanco `#FFFFFF`.
