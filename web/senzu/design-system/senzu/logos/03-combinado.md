# 03 · Combinado (símbolo + palabra)

**Se genera DESPUÉS de fijar el símbolo y el logotipo**: no es una tercera exploración, es la
composición de las dos piezas elegidas. Sin la ronda de 01 y 02 cerrada, no se empieza.

## Versiones que hay que entregar
| Versión | Uso | Regla |
|---|---|---|
| Horizontal | cabecera de la web, portada del README | símbolo a la izquierda, altura del símbolo = altura de las mayúsculas + ascendentes |
| Vertical | portada, redes, presentaciones | símbolo encima, centrado |
| Solo símbolo | favicon, avatar | el de 01 |
| Monocromo negativo | fondos oscuros | todo en blanco |

- **Zona de respeto**: alrededor, como mínimo la altura de la `s` en todos los lados.
- **Tamaño mínimo**: horizontal 96 px de ancho; por debajo, solo el símbolo.
- Se dibuja en **SVG** a partir de las piezas fijadas (no se pide a la IA: la composición es exacta).
