# 04 · Mascota

**Uso**: portada de la web (ilustración del hero), página 404, estados vacíos, redes, stickers.
**No sustituye al logo**: es un personaje de apoyo. Si no convence, la web funciona sin mascota.

## Cuidado con el guiño
Nada que recuerde a un personaje de Dragon Ball: ni el anciano ermitaño con gafas y barba, ni
estética anime, ni la judía verde dibujada como en la serie. Personaje **original**.

## Dirección A · «Semi», la semilla con carácter
Una semilla ovalada con dos ojos sencillos y un pequeño brote en la cabeza; expresiones según la
situación: concentrada (verificando), con la mano en alto (muro que bloquea), satisfecha (todo verde).
```
Original mascot character for "Senzu", a developer tool. A small rounded oval seed with two simple
dot eyes and a tiny two-leaf sprout on top. Flat vector illustration, thick clean outlines, limited
palette of 2-3 colors, friendly but not childish. Show 3 poses: focused, raising a hand to stop,
happy thumbs up.
Style: flat vector character, minimal, modern sticker style.
NOT: anime, Dragon Ball, green bean from the series, kawaii overload, 3D render, gradients.
```

## Dirección B · El jardinero de proyectos
Un pequeño personaje con regadera y gorra de trabajo que cuida un jardín de archivos (carpetas como
macetas). Habla de cuidar y ordenar, no de magia.
```
Original mascot for "Senzu": a small friendly gardener character with a work cap and a watering can,
tending plant pots shaped like code folders. Flat vector, thick outlines, 3 colors, warm and
competent, not childish.
Style: flat illustration, editorial, modern.
NOT: anime, old hermit, sunglasses, beard, Dragon Ball, 3D, photorealistic.
```

## Dirección C · Sin personaje: la semilla como objeto vivo
Ilustración del símbolo elegido «en acción» (semilla que se abre y de la que salen las piezas de un
proyecto ordenado) en lugar de un personaje. Más sobria, encaja con la maqueta técnica.
```
Editorial flat illustration for the "Senzu" developer tool homepage: a small seed opening, and from
it emerge neatly organized elements of a software project (folders, a checklist, a shield, a
terminal window), arranged in an orderly arc. Flat vector, limited palette, lots of negative space.
NOT: anime, Dragon Ball, characters, 3D, glow, sparkles, busy composition.
```

## Qué preguntar al usuario
¿Mascota (A o B) o ilustración sin personaje (C)? ¿Encaja con el tono de la maqueta elegida?
