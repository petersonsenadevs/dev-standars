# 02 · Logotipo (la palabra)

**Uso**: README, pie de la web, firmas, textos donde no cabe el símbolo.
**Debe**: «senzu» en minúsculas (más cercano; las mayúsculas suenan a marca corporativa), legible a
14 px de alto, sin efectos.

## Dirección A · «senzu_» terminal
Monoespaciada, con un cursor (`_` o `▍`) al final, como si se acabara de escribir en la terminal.
Base: JetBrains Mono o Geist Mono en peso 600, con la `z` retocada.
```
Wordmark logo "senzu_" in lowercase monospace letters, weight semibold, followed by a terminal
underscore cursor. Clean, technical, flat vector, tight but even letter spacing.
Style: monospace, developer tool, minimal.
Colors: single color, near-black.
Requirements: only the word, no symbol, horizontal, white background.
NOT: anime font, brush, 3D, glow, gradient, decorative serif.
```

## Dirección B · Geométrica redonda con punto-semilla
Sans geométrica redondeada; el punto de una letra imaginaria o el remate de la `u` es una pequeña semilla
ovalada (si se elige el símbolo A o C, esa semilla es la misma).
```
Wordmark logo "senzu" in lowercase rounded geometric sans-serif, medium-bold weight. The final "u"
ends with a small solid oval seed as a terminal dot. Friendly, modern, flat vector, even spacing.
Style: geometric sans, rounded, minimal, approachable.
Colors: single color.
Requirements: only the word, horizontal, no gradients.
NOT: anime font, cartoon, 3D, glow, sparkles.
```

## Dirección C · Editorial con carácter
Serif de contraste (tipo Fraunces o Instrument Serif) en cursiva suave: Senzu como «oficio», no como
gadget. Encaja con la maqueta editorial clara.
```
Wordmark logo "senzu" in lowercase high-contrast serif, soft italic, elegant but warm, with a
distinctive "z". Flat vector, single color, editorial magazine feel.
Style: editorial serif, refined, crafted.
Colors: single color, deep ink.
Requirements: only the word, horizontal.
NOT: script handwriting, wedding style, 3D, gradients, anime.
```
